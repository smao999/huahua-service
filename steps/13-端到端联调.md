## 13.1 字段名对齐——最重要的检查项

**前端硬编码读取字段名**，大小写和拼写不一致就崩了。

```python
# Python 返回的字段名示例
{
    "fund_code": "000001",         # 注意是下划线
    "access_token": "eyJ...",      # snake_case
    "token_type": "bearer",
    "winRateTable": [...],         # 驼峰！有些字段是 camelCase
}
```

```go
// Go 必须完全一致
type TokenResponse struct {
    AccessToken string `json:"access_token"`   // 字段名和 Python 一样
    TokenType   string `json:"token_type"`
}

type FundDetailResult struct {
    WinRateTable interface{} `json:"winRateTable"` // 和 Python 一致
}
```

**犯错场景**：
```go
// 如果 Python 返回 "fund_code"，但 Go 返回 "fundCode"
// 前端读 response.fund_code → undefined → 页面白了
```

## 13.4 常见问题排查

```
问题：Go 返回 404，但 Python 正常
原因：路由顺序错了！具体路由必须写在通配路由前面

问题：Go 返回 400，提示字段绑定失败
原因：json tag 和 binding tag 写错了

问题：Go 返回 500 Internal Server Error
用 slog.Debug 加日志：slog.Debug("debug", "v", v)
```

package handler

import (
    "encoding/json"
    "net/http"
    "net/http/httptest"
    "testing"
    "github.com/gin-gonic/gin"
)

func TestHealthPing(t *testing.T) {
    // 1. 创建 Gin 引擎（不带外部依赖）
    gin.SetMode(gin.TestMode)
    r := gin.New()
    h := NewHealthHandler()
    r.GET("/api/health", h.Ping)

    // 2. 发起请求
    req := httptest.NewRequest("GET", "/api/health", nil)
    w := httptest.NewRecorder()
    r.ServeHTTP(w, req)

    // 3. 验证
    if w.Code != http.StatusOK && w.Code != http.StatusServiceUnavailable {
        t.Errorf("期望 200 或 503，得到 %d", w.Code)
    }
    var resp map[string]interface{}
    json.Unmarshal(w.Body.Bytes(), &resp)
    if resp["status"] == nil {
        t.Error("响应缺少 status 字段")
    }
    t.Logf("响应: %+v", resp)
}
