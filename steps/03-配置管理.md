# Step 3：配置管理

> **目标**：把端口号、数据库地址等配置项从代码里抽到环境变量 / .env 文件。

---

## 3.1 为什么需要配置

现在端口 `:8080` 是写死在 `main.go` 里的。如果服务器要换端口、换数据库，
你不想改代码重新编译——应该改 .env 文件就行。

## 3.2 创建 config 包

```go
// internal/config/config.go
package config

import (
    "os"
    "strconv"
)

// Config 集中管理所有配置
type Config struct {
    Port string
}

// Load 从环境变量读取配置
// 如果环境变量没设置就用默认值
func Load() *Config {
    return &Config{
        Port: getEnv("PORT", "8080"),
    }
}

func getEnv(key, defaultVal string) string {
    if v := os.Getenv(key); v != "" {
        return v
    }
    return defaultVal
}

func getEnvInt(key string, defaultVal int) int {
    if v := os.Getenv(key); v != "" {
        if n, err := strconv.Atoi(v); err == nil {
            return n
        }
    }
    return defaultVal
}
```

## 3.3 更新 main.go 使用配置

```go
// cmd/server/main.go
package main

import (
    "huahua-service/internal/config"
    "huahua-service/internal/handler"
    "huahua-service/internal/router"
    "github.com/gin-gonic/gin"
)

func main() {
    cfg := config.Load()
    
    r := gin.Default()
    h := handler.NewHealthHandler()
    router.Register(r, h)
    
    r.Run(":" + cfg.Port)  // 端口从配置读取
}
```

## 3.4 创建 .env 文件

在项目根目录创建 `.env`：

```env
PORT=8080
```

## 3.5 验证

```bash
# 默认端口
go run cmd/server/main.go

# 换端口
PORT=9090 go run cmd/server/main.go
curl http://localhost:9090/api/health
# {"status":"ok"}
```
