# Step 2：项目结构拆分

> **目标**：把 Step 1 单人文件中的 handler、router 拆到独立文件，为后续扩展做准备。

---

## 2.1 为什么要拆分

所有代码写在一个 `main.go` 里，项目稍微变大就乱成一锅粥了。
Go 项目的惯例是按职责分包：

```
router/    —— 只做路由注册（URL → handler 的映射）
handler/  —— 处理 HTTP 请求（绑参数、调 service、返回响应）
```

## 2.2 创建 handler 文件

```go
// internal/handler/health.go
package handler

import (
    "net/http"
    "github.com/gin-gonic/gin"
)

type HealthHandler struct{}

func NewHealthHandler() *HealthHandler {
    return &HealthHandler{}
}

// Ping 健康检查——返回最简单的 ok
func (h *HealthHandler) Ping(c *gin.Context) {
    c.JSON(http.StatusOK, gin.H{"status": "ok"})
}
```

## 2.3 创建 router 文件

```go
// internal/router/health.go
package router

import (
    "huahua-service/internal/handler"
    "github.com/gin-gonic/gin"
)

func registerHealth(rg *gin.RouterGroup, h *handler.HealthHandler) {
    g := rg.Group("/health")
    g.GET("", h.Ping)  // GET /api/health
}
```

```go
// internal/router/router.go
package router

import (
    "huahua-service/internal/handler"
    "github.com/gin-gonic/gin"
)

func Register(r *gin.Engine, h *handler.HealthHandler) {
    api := r.Group("/api")
    registerHealth(api, h)
}
```

## 2.4 更新 main.go

```go
// cmd/server/main.go
package main

import (
    "huahua-service/internal/handler"
    "huahua-service/internal/router"
    "github.com/gin-gonic/gin"
)

func main() {
    r := gin.Default()
    
    h := handler.NewHealthHandler()
    router.Register(r, h)
    
    r.Run(":8080")
}
```

## 2.5 验证

```bash
go run cmd/server/main.go
curl http://localhost:8080/api/health
# {"status":"ok"}
```

**和 Step 1 的结果完全一样**，但代码已经放到了合理的包里。

- ✅ router 抽到独立文件
